# 2026-09-24

## direct messages are commands

`handleMessage` falls through to "the whole message is the command" when the `posted` event's `channel_type` is `D` and neither a trigger word nor an @mention matched. The mention path still runs first so a DM that happens to @mention the bot is stripped the same way as in a channel. This came from astrometrics, whose two agents run one bot each and want a bare `status` in a DM to work; sexton's private copy of this client does not have it. Tagging as v0.1.2 is the operator's; astrometrics pins v0.1.1 until then and its chat commands answer @mentions in the channel meanwhile.
